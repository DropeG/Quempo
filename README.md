# Faredeo 🏔️🚗

**Faredeo** es la plataforma de viajes compartidos (carpooling) especializada para la comunidad de montaña y deportes de nieve en Santiago de Chile. Conecta a conductores que suben a los centros de ski (Farellones, El Colorado, La Parva, Valle Nevado) con pasajeros que buscan subir y bajar de la cordillera de forma rápida, cómoda y segura.

---

## ⚡ Características Principales

- **Descubrimiento instantáneo (< 2s)**: Alternador de sentido (Subida ⬆️ / Bajada ⬇️) y selector de fechas inmediatas (Hoy, Mañana, Calendario).
- **Contacto Directo por WhatsApp**: Conexión P2P en 1 clic a WhatsApp con mensaje pre-llenado con los datos del viaje.
- **Login rápido con Google**: Autenticación rápida mediante Supabase Auth.
- **Estética Impeccable "Obsidian Night & Pure Snow"**: Interfaz oscura de alto contraste responsiva (mobile-first).

---

## 🚀 Inicio Rápido

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```

3. Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

---

## 🛠️ Tecnologías

- **Framework**: Next.js 16 (App Router)
- **UI & Estilos**: React 19, Tailwind CSS v4, Lucide Icons
- **Backend & Auth**: Supabase (PostgreSQL + Google OAuth)
- **Despliegue**: Vercel
