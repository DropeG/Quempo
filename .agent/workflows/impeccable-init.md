# Impeccable Init Workflow

Este workflow inicializa el contexto de diseño Impeccable en el proyecto actual.

## Pasos

1. **Analizar la estructura del proyecto**:
   - Inspeccionar los componentes existentes en `src/`, configuración de Tailwind/CSS, fuentes y paleta de colores.

2. **Crear `PRODUCT.md`**:
   - Analizar la aplicación y definir:
     - Propósito del producto.
     - Audiencia objetivo y propuesta de valor.
     - Principales flujos de usuario.
     - Tono de voz y experiencia deseada.

3. **Crear `DESIGN.md`**:
   - Definir el sistema de diseño visual Impeccable para este proyecto:
     - Sistema de diseño de tokens (variables CSS / Tailwind).
     - Paleta de colores primaria, secundaria, neutral y de acento (evitando combinaciones genéricas).
     - Tipografía y escala tipográfica (jerarquía clara de títulos, cuerpo y etiquetas).
     - Espaciado, elevación y bordes.
     - Reglas de movimiento y micro-animaciones.

4. **Confirmar creación**:
   - Mostrar un resumen de los archivos `PRODUCT.md` y `DESIGN.md` creados.
