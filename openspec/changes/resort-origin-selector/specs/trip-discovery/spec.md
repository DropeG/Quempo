## ADDED Requirements

### Requirement: Specific Resort Origin/Destination Sub-menu
The system SHALL display a sub-menu selector when displaying the "Centro de Ski" node in the Direction Swap bar.

#### Scenario: User selects a specific ski resort
- **WHEN** user chooses a specific resort from the sub-menu (El Colorado, La Parva, Valle Nevado, or Farellones)
- **THEN** system filters the trips list to match the selected resort as origin (in Bajada) or destination (in Subida).

### Requirement: Standardized Labeling
The system SHALL use "Centro de Ski" instead of "Cordillera" across all directional search labels.
